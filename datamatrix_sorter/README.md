# Сверка кодов «Честный знак» (М1 → М2 → М3) и печать DataMatrix

Десктоп-программа на Python, офлайн, без API-ключей.

## Запуск
1. Python 3.9+ (на Windows при установке отметить Tcl/Tk — по умолчанию включено).
2. `pip install -r requirements.txt`
3. `python app.py` (или `run.bat`). Консольный режим: `python cli.py --help`.
4. Один .exe: `build_exe.bat` (на Windows) → `dist\CHZ_Sverka.exe`.
5. Проверка ядра: `python selftest.py`.

## Как работает
1. **М1** (старая) и **М2** (свежая инвентаризация): добавьте файлы txt / xlsx / csv.
   В txt — по коду в строке; в xlsx — коды в любых ячейках любых листов.
2. «Сформировать М3»: из каждого набора убираются брак и повторы; **М3 = коды из М1, которых нет в М2**
   (сравнение по `01+GTIN+21+серийный`, криптохвост при сравнении не учитывается, в М3 остаётся
   криптохвост из М1).
3. Вкладка «М3»: отбор по части кода (GTIN, EAN-13, кусок серийного номера; несколько условий через
   пробел = «или»), сортировка.
4. «Создать PDF»: сетка на A4, сторона кода от 10 мм (по умолчанию 15), код с криптохвостом и
   разделителями GS (FNC1), подпись под кодом. Печатать в масштабе **100%**.
5. «Тестовый лист размеров»: один код размерами 10–25 мм — найти минимальный размер, который читает
   ваш сканер/касса.
6. Экспорт: XLSX, коды без криптохвоста для ЧЗ (общий файл и по файлу на GTIN), список брака.

## Что считается браком
Штрихкоды EAN-13 и ссылки вместо кодов, обрезанные коды (нет криптохвоста), символы вне ASCII
(ошибка считывания), неверная контрольная цифра GTIN, длина серийного номера вне 1–20.
Склеенные коды разделяются; лишний мусор в начале/конце отбрасывается и попадает во вкладку «Брак и поправки»
как «поправка».

## Самопроверка
Каждый код перед печатью: кодируется → декодируется обратно → сравнивается с исходным. Выборочно
(и всегда, если установлен `zxing-cpp`) проверка идёт через картинку. Не прошедшие коды в PDF не
попадают, список сохраняется рядом.
**Это не заменяет проверку на реальном сканере и кассе.**

## Ограничения
- Группа товара определяется по GTIN (по коду её не узнать); разбивка идёт по GTIN.
- Формат файла для загрузки в ЧЗ — просто коды без криптохвоста; если ЧЗ требует другой шаблон, это правится в `chz_core.export_*`.
- `.xls` (старый Excel) не читается — пересохраните в `.xlsx`.
